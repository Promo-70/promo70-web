## Flujo de contribución

Crear una rama de trabajo y un PR hacia dev. La integración en main requiere otro
PR y dos aprobaciones según las reglas del repositorio; dev requiere una.

Referenciar explícitamente el trabajo de Taiga: SI-T42 para tarea, SI-H12 para
historia o SI-I9 para incidencia. Un PR integrado no marca el ticket como Listo.

No se ha elegido tecnología ni configurado despliegue o CI/CD en este inicio.
